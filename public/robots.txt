# One wildcard block on purpose. A named User-agent block REPLACES this one for
# that crawler rather than adding to it, so spelling out GPTBot, ClaudeBot,
# PerplexityBot etc. would quietly hand them /admin and /thank-you unless every
# Disallow below were repeated in each block. The wildcard already allows them,
# which is what we want: AI answer engines are welcome to read and cite the site.
# There is deliberately no Google-Extended block — that would opt the site out
# of Google's AI surfaces.
User-agent: *
Allow: /
Disallow: /thank-you
Disallow: /blog/drafts
Disallow: /admin

# the same host it lists.
